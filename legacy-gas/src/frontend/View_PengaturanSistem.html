Pengaturan Sistem

Pencadangan Sistem

Buat salinan cadangan (snapshot) data pegawai dan dokumen kepegawaian. Backup disimpan di Google Drive pada folder SIKAP_Backups dan tidak mengubah data asli.

table_chart

Backup Database

Mencadangkan semua data dari Spreadsheet (Data Pegawai, Arsip Dokumen, Log Aktivitas). Proses cepat, selesai dalam hitungan detik.

folder_zip

Backup Penuh

Mencadangkan Database dan seluruh file dokumen yang telah diunggah di Google Drive. Proses lebih lama bergantung jumlah file.

info

Backup Penuh yang melibatkan banyak dokumen dapat memerlukan waktu hingga beberapa menit. Jangan tutup browser selama proses berlangsung. Hasil backup akan tersedia di folder SIKAP_Backups di Google Drive akun Anda.

Pengaturan Notifikasi

Aktifkan atau nonaktifkan notifikasi WhatsApp untuk setiap jenis event dokumen. Perubahan berlaku langsung.

upload_file

Dokumen Baru / Diperbarui

Kirim notifikasi ke Admin saat pegawai mengunggah atau memperbarui dokumen.

check_circle

Dokumen Disetujui

Kirim notifikasi ke Pegawai saat dokumen mereka telah diverifikasi/disetujui.

cancel

Dokumen Ditolak

Kirim notifikasi ke Pegawai saat dokumen mereka ditolak beserta alasan penolakan.

Memeriksa status...

Ditemukan di Meta Developer → WhatsApp → API Setup → Phone Number ID.

info

Pesan uji dikirim ke nomor HP Anda yang terdaftar di Data Pegawai. Meta Cloud API hanya dapat mengirim pesan ke nomor yang sudah pernah menghubungi nomor bisnis Anda, atau yang sudah terdaftar di Meta Business.
Gunakan Token Permanen (System User Token) untuk menghindari token kedaluwarsa.
